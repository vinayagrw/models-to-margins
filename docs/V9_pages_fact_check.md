# V9. Fact check of the two published pages

Checked 2026-10-25 by a fresh checker with no prior context.

- Page 1: `drafts/frontier-challenges-src.html` (Frontier AI Pain Points). Evidence: `docs/Frontier_AI_Challenges_User_Research.md` Appendix A, A2 and A3, plus `docs/Frontier_AI_Challenges_research/`.
- Page 2: `drafts/src.html` (Where AI Search Breaks). Evidence: `docs/AI_Web_Search_Failures_Technical_Design.md` Appendix A, plus `docs/AI_Web_Search_Failures_research/`.

Method. Every source URL below was fetched on 2026-10-25 with `curl -sL` (Chrome user agent) and turned into text with BeautifulSoup or pypdf. GitHub issues were read through the GitHub API. Where curl got 403, WebFetch or a Wayback copy was tried and the row says which. Internal claims (scores, tiers, verdicts, segment lists, matrix cells, map positions, scorecard grades) have no outside source. They were checked against the doc tables, and the row says "doc" in the URL column.

Status key. **verified**: the opened source shows the same number and meaning. **unverified**: the source could not be opened, or the claim has no ledger row and no source. **wrong**: the number or meaning differs, or the page says more than the source. Minor wording drift is marked wrong, with "(minor)".
