# Interim quick fixes for the 14 frontier problems (F1 to F14)

Researched 2026-10-26. Each fix below is something a team can start this week with tools it already pays for, a manual practice, or a contract letter. Each one is backed by a page opened on 2026-10-26 and listed in the ledger. These are stopgaps. Each row names the target building block that replaces it and the signal to switch. Effort hours are illustrative estimates, not measured.

Most fixes are a vendor's own feature described on the vendor's own page, so they are tagged [vendor]. The ledger shows that a setting exists. It does not show that the setting works well.
