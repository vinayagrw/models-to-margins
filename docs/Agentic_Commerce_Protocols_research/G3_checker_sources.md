# G3 checker sources, claim ids for pages the Wave 3 checkers opened

As of 2026-11-15. The Wave 3 checkers (W3_K1 to W3_K6) opened pages that had no claim id, and F1 cited them as plain text (W3_applied.md, "Verdicts not applied", item 5). This file gives each one an id in the 13 column format of R4_risk.md, so the doc, the page data and ledger.py can cite it. Ids G-201 to G-207.

Method. URL and date come from the checker files (W3_K1.json, W3_K2.json, W3_K3.md). Quotes are the checker's recorded words where the checker quoted the page. Where the checker recorded only a paraphrase (Visa rules, EUR-Lex, payment-law.eu), the page was opened again on 2026-11-15 and the quote copied from it. The Stripe newsroom and the Microsoft page were also opened again, to see what each one supports.

Not given a new id:

- Visa UK press release of 2026-07-02 (visa.co.uk, release 3457328). It is the same release as G-34 (the mynewsdesk copy of release 3457328, same date and title), so the doc cites G-34 for it, including the TAP line: "Merchants' participation was enabled through Visa's Trusted Agent Protocol (TAP)."
- A2A GitHub release page for v1.0.1. K1 asked for it, but no checker recorded a URL, and v1.0.1 was dropped from the doc, so nothing cites it.

Corrections found while opening the pages:

- The Stripe newsroom (G-204) does not say where Shared Payment Tokens are available. The line "SPTs are available to agents, customers and sellers in the US, Canada and select European countries" came from Stripe's docs (R2-15 is the SPT docs page K1 opened), so the doc now cites R2-15 for it.
- The Stripe newsroom uses future tense for the US launch. Current availability of Copilot Checkout rests on Microsoft's page (G-205).
