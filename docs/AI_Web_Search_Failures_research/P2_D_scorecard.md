# P2-D Evidence-only scorecard: why AI assistants miss the right details when they search the web

Compiled 2026-10-25. Built from U2 section 3, then widened with new searches. Every number below comes from a page or file opened in this session (the "Opened" column says so). Vendor self-reports sit only in section 3.

## How to read this

- **Grades.** Better than peers, Mixed, Worse than peers, Not enough data. A grade is given only when at least one independent study puts this product next to at least two other products on the same metric. "Mixed" means the studies point different ways, or the product's modes split (for example quick search vs deep research). A single study where the product lands in the middle is "Not enough data".
- **No averaging.** Each cell names its own studies. Numbers from different tasks are never combined.
- **STALE flag.** Vendors shipped several model generations between 2025 and late 2026 (for example GPT-5 to GPT-5.6, Gemini 2.5 to Gemini 3.6, Claude 3.7 to Claude 5). So any test run before 2026-01-01 is treated as more than one generation old and marked STALE. A cell is STALE when all of its evidence is STALE.
- **Product scope.** "Claude" covers Claude.ai, the API with search, and Claude Code. "ChatGPT" covers ChatGPT search, Deep Research, Atlas and OpenAI API models with search. "Gemini" covers the app, Deep Research, API grounding and Gemini in Chrome. Google AI Overviews and AI Mode are a separate column because they are tested separately.
- **E-numbers** point to the evidence table in section 2.

## 4. Honest limits of comparing these products

1. **Most per-product numbers are STALE.** 34 of the 53 evidence lines (16 of 32 studies in full) were collected before 2026. Gemini 3, GPT-5.x and Claude 4.5 or 5 have changed sourcing, search depth and refusal habits since then. Oumi even found grounding got worse from Gemini 2 to Gemini 3 while accuracy rose.
2. **Products, modes and tiers are not the same thing.** One brand can be best and worst at once. Perplexity Deep Research had the best DRB citation accuracy but the worst DeepTRACE unsupported rate. ChatGPT Search came last on Mind2Web 2 while OpenAI Deep Research came first. A single grade per brand hides this.
3. **Many 2026 tests use API models in research harnesses, not consumer apps.** LivePI ran in OpenClaw, LifeSearch, HAE-GEO and the PwC study used their own agent loops, and Suzgun used APIs with native search. Consumer apps add their own search stack, prompts and safety layers.
4. **Coverage is uneven.** Copilot and Grok appear in almost no 2026 study. Google AI Mode has one assessment. Snippet-only reading was measured for one OpenAI API model only. Claude Code has a security advisory and nothing on search quality.
5. **Some authors have a stake.** DeepTRACE has a Microsoft co-author (Copilot). LifeSearch and EvoBrowseComp come from Tencent, which makes rival models. Oumi judged with its own model. Cloudflare sells bot blocking. Brave sells a rival browser. SearchViu and Crawl Readiness sell SEO services.
6. **Judges and samples are small or automated.** NewsGuard tests 30 prompts per bot, so one answer moves a rate by 3.3 points. Suzgun's false-premise set is 100 items per model. Many citation studies use an LLM judge.
7. **Some rows measure the web, not the product.** Crawler blocking (row 7) is a site owner's choice. A higher block rate for GPTBot says more about publisher deals than about ChatGPT's reading skill.
8. **Declining is not the same as being right.** Copilot gets "Better than peers" on silent failure because it declines more, but that also means it answers fewer questions.
9. **Stale facts (row 5) and memory over search (row 9) have almost no per-product rates.** These are among the most reported user complaints, yet the evidence is mostly single examples.
