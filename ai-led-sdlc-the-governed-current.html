          03 — FROM PILOT TO THE WINNING 5%

          A pilot proves the tool works. The gate proves the org is ready.

          ~95% of GenAI pilots show no measurable P&L return — not because the tech fails, but because the organisation can't absorb it safely or profitably. Integration, cost-at-scale, governance, adoption, and review capacity are the filter into the lit cohort.

          04 — THE TEAM TRANSFORMATION

          From coding to orchestration.

          Measure the new job, not the old one. Output is no longer what you type — it is what you can safely merge, and review is the deliberate constraint, not a delay to engineer away.

          ↤ the old shape
          • Engineer writes the code
          • Output ≈ lines you personally type
          • Review is a courtesy step
          • Skills: syntax, speed, recall
          • Manage by individual activity
          ⟶
          ↦ the orchestration shape
          • Engineer specifies, steers, verifies fleets
          • Output ≈ what you safely merge
          • Review & integration is the bottleneck
          • Skills: judgment, architecture, taste
          • Manage by system outcomes, not LOC

          The technology is commoditising fast. The governed current — measuring honestly, holding the human gate, rebuilding teams — is where delivered value is actually won.
