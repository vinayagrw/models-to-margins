Gate 1 · Routine
Is the signal routine and rule-decidable, no judgment needed?
If a rule can decide it, a rule should. LLM tokens on the easy majority is the first anti-pattern.
Gate 2 · Variety
Do multiple distinct signal classes arrive at the same front door?
Routing is cheap, observable, and essential at ops event volumes. One handler per class beats one prompt for all.
Gate 3 · Diagnosis
Does resolving it require cross-system diagnosis, inventory plus carrier plus labor?
Yes means an orchestrator decomposing checks to parallel workers. No means a linear document-style chain.
Gate 4 · Stakes
Is this contested or high-value residue, a claim someone will dispute?
A generate → verify loop earns its cost only here. Everywhere else it is expensive theater.
Gate 5 · Action risk
Is the resulting action high-risk or unproven for this category?
Autonomy is earned per category with shadow evidence, never assumed. Money and physical ops start gated.
