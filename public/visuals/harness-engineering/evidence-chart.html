* The confound attached to this group

Harness-induced belief divergence, July 2026. Harness configuration changes what the agent believes mid-run while leaving terminal success rates intact. A harness-only delta is therefore a claim about a system, not a clean measurement of a model — and scores must never be compared across harnesses. Treat the harness as an experimental variable and report it alongside the number.

The pattern. None of these teams beat the next model. They beat the previous version of themselves by re-engineering the system around the model — fewer tools, tighter verification, environmental controls instead of prompts. Read each group on its own scale, and read Group A with the asterisk attached.
