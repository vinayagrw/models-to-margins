Order is the design. Classify → residency → cache → tier → redact → invoke → log. Residency is evaluated first because it is a constraint, not an optimisation; capability and cost rules then apply only to whatever survives it.

Three terminal exits, all fail-closed. A · blocked by residency B · over quota C · fallback outside the boundary

A cache hit returns a completion with no model call made and no backend edge traversed. Exit C is the one teams miss: your outage procedure is also a data-export procedure — a fallback tier in another jurisdiction breaks residency at exactly the wrong moment.

Wire detail. Publishes an enforced set, not a recommendation. If the set empties after the residency filter, the request terminates at exit A rather than degrading to a non-compliant backend. Sovereign-region managed deployment moves this boundary without you running anything.

Wire detail. Version pinning matters more than model choice: a silently rotated model id is an un-versioned production change. Open weights served managed keep an exit — the same weights lift onto your own GPUs later. The appliance position inverts custody: vendor weights, your prompts, your logs, your premises.

Self-hosted serving cluster Open weights on your GPUs — nothing leaves the network
Inside your perimeter
Weights store — versioned, checksummed Ingress / load balancer Inference servers — vLLM / SGLang GPU pool

Aggregated topology. One inference tier does prompt processing and token generation on the same GPUs. Simplest to run; the two phases fight each other for the same silicon.

Disaggregated topology. Prefill tier — compute-bound, bursty, scales on queued prompt tokens hands a KV cache to Decode tier — memory-bandwidth-bound, long-running, scales on concurrent sequences. Two tiers, two scaling signals, one extra failure mode: the handoff.

The GPU pool bills whether or not it is busy. That is the whole economic difference from a metered API, and it is why utilisation is the variable that decides this, not sticker price.

Wire detail. The audit record is the answer to the only two questions ever asked afterwards: which model saw this customer’s data, and what did it cost. Prompt hash, model id, policy decision, token counts, cost — one immutable line per call.

Economics is a structure, not a number. This page publishes no break-even figure and no GPU price, because both are yours to supply. The self-host line is a function of these variables and nothing else:

GPU $/hour number of GPUs utilisation % tokens per month managed API $/M tokens platform engineering FTE cost

Measure the numerator as cost per successful completion. A cheaper model that fails and retries is not cheaper.
