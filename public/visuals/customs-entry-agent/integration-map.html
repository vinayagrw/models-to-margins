Ten external systems, ten contracts

Every system that touches this platform has a written contract. It sets how the data arrives, how often, what makes a repeat a repeat, and what happens when it fails.

Fifteen systems over one drawing, nine steps, and a contract card on every one.

Three groups, one boundary

The rule that does the workGrey frames sit outside the platform › coloured frames sit inside it

  • 3 inCustomer and partner systemsThe importer ERP or TMS, supplier email, EDI over AS2. Untrusted, so everything lands in one sandboxed intake. Each source repeats itself differently, so each carries its own idempotency key.
  • 4 inAuthority feeds, read onlyThe Federal Register, CBP CSMS, the USITC tariff schedule, the CROSS rulings corpus. One watcher each, with its own alarm at 24 hours without a successful poll.
  • 3 outGovernment, and back to the customerOne deterministic filing path to CBP that contains no model, the agency message sets inside the same transmission, and the exposure export that files nothing.
