The real cost centre Reviewer minutes dominate total cost at any realistic token price. Optimising model cost is the wrong optimisation. Optimise Tier 0 hit rate and review-queue UX.
How the target is met The under-15%-of-human-cost target is achieved through the tier mix, not model selection. If the mix is wrong, no model is cheap enough to rescue it.
