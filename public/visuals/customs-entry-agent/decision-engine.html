Sequencing

Workers run in parallel where independent, sequentially where dependent. Origin and program eligibility depend on classification, so they wait for the Classifier.

The validator gauntlet · deterministic, in order
✓ Citation verification every cited ruling must resolve to a real document, hallucinated authority = automatic Tier 2
✓ HTS existence and depth code exists, notes do not exclude it
✓ Arithmetic line values reconcile to invoice totals, duty = rate x value
✓ Cross-field consistency UOM matches the HTS unit, origin matches the certificate, PGA flags match the classification
✓ Schema conformance ABI/ACE record format

Deterministic checks run FIRST. They are free, perfectly reliable, and kill a whole class of error before any money is spent on calibrated confidence. The model adjudicates only the residue.
